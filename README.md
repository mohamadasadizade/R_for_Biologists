## 🧬 Course Overview

This course is designed for biologists who want to learn R programming
for data analysis and scientific research.

The course focuses on practical examples from biology and introduces
R programming step by step.

### Topics covered

- R fundamentals
- loop and condition implementation
- working with biological sequences
- Data structures
- Data manipulation
- Data visualization
- Statistical analysis
- Intro to genetic variant and transcription count data
